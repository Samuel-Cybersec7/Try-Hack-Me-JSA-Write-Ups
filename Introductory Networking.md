## What I Learned
### 1. OSI Model 7 Layers
- **L7 Application**: Accepts requests from end users. Ex: FTP, HTTP
- **L4 Transport**: TCP uses "Segments". UDP used for Live Video
- **L3 Network**: Handles Logical Addressing - IP Addresses

### 2. Key Quiz Answers
- TCP data pieces = Segments
- FTP = Layer 7
- Logical Addressing = Layer 3
